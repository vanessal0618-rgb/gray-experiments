# Gray — visual experiments

Interactive art-direction tools for Gray ("The World's Inference, Filtered").
Each folder is one self-contained tool: open its `index.html` in a browser, or use the live link.

- Live site: the repo's GitHub Pages URL (see the repo's About section).
- Every tool has a control panel. Most have **Copy / Load settings** so you can share a look as JSON.
- Exports (PNG / video) save to your Downloads folder.

## Tools

See `index.html` for the full list with descriptions. New tools are added one at a time with their approved default settings.
